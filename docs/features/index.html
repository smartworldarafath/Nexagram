Feature list

Enhancements Nexagram adds on top of official Telegram applications, folded by category; select a category to expand it. A check mark means the client implements it natively.

Shared across platforms

These features are implemented across Nexagram Android and Windows Desktop.

  • Liquid Glass Optics

    Physics-based acrylic blur, reflective sheen, and smooth responsive elevation curves on modern screens.

  • Forced Copy

    Bypass channel copy restrictions to save text, links, and content directly to your clipboard.

  • Multi-Provider Translation

    Choose Google, Microsoft, Yandex, DeepL, or hook up your custom OpenAI / Claude LLM endpoint.

  • Message Filters & Formatting

    Match messages by keyword or regex to mask, hide, or prioritize; format text with rich typography.

  • Hide Sponsored Ads

    Sponsored messages in channels and recommended channels are automatically hidden.

  • Hardened Privacy

    Zero telemetry, no Google/Firebase analytics pings, and complete offline settings export and import.
