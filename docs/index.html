The Nexagram family builds on the official Telegram clients and adds translation, message filters, repeat and more, on Android, iOS and desktop.

Products

Four clients, each tracking the upstream Telegram source for its platform. See the feature list for what each one adds.

Nexagram Android

Android 5.0 or later

The flagship client, tracking Telegram Android. Supports rich translation providers, chat and message filters, local premium icons, forced copy, and more.

Latest version v2.3.2

Stable · Universal APK Stable · arm64-v8a Beta · Telegram channel Releases page Source

Nexagram iOS

iOS 15.0 or later

Based on the official Telegram-iOS source. Releases are published on GitHub Releases and beta updates in the Telegram channel.

Latest version v2.3.0

Download · GitHub Download · Telegram Source

Nexagram Desktop

Windows · macOS · Linux

Based on Telegram Desktop. Installers are published on GitHub Releases; the download buttons open the latest release page.

Latest version v2.3.0

Download · Windows Download · macOS Download · Linux Releases page Source

Nexagram Core

Android 8.1 or later · arm64-v8a

A leaner build based on Nullgram with a largely similar feature set. Builds are posted to GitHub Releases and the Telegram channel.
